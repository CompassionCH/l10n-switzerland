In the menu *Accounting \> Configuration \> Management \> Payment
Methods*, select the payment method that has the code
*sepa_direct_debit* and set the *PAIN Version* to *pain.008.001.02.ch.03
(direct debit in Switzerland)*.

On the company bank account used by the direct debit payment mode (journal
bank account), set the *ISR Participant Number* (e.g. 01-12345-6). It is
required by SIX in the *CdtrAgt/FinInstnId/Othr/Id* element of LSV+ / BDD
files.
